# Ciclo BMAD: correzioni dopo il feedback del 27 ottobre 2026

Questa cartella contiene gli artefatti del metodo BMAD (Analyst → PM → Architect → Scrum Master → Dev → QA) applicato al feedback d'uso raccolto il 27 ottobre 2026. L'installer `bmad-method` non è stato usato (bloccato dal classificatore di sicurezza della sessione): i ruoli sono stati interpretati a mano, producendo gli stessi documenti.

| Fase | Ruolo | Documento |
|---|---|---|
| Analisi | Analyst | `brief.md`: i sei problemi segnalati, con le prove raccolte dal codice e dal registro delle operazioni |
| Requisiti | PM | `prd.md`: epic, storie e criteri di accettazione |
| Architettura | Architect | `architecture.md`: dove si interviene, livello per livello, e perché |
| Pianificazione | Scrum Master | `stories.md`: le storie pronte per lo sviluppo, con compiti e test |
| Sviluppo e verifica | Dev + QA | `qa.md`: esito dei test, della build e della revisione finale |
